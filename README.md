## 🚀 Deployment to Vercel

### Option 1: Vercel CLI
```bash
cd elitewoods-website
npx vercel
```

### Option 2: GitHub / GitLab / Bitbucket
1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Elitewoods website"
   ```
2. Push to your GitHub repository.
3. Import the repo at [vercel.com/new](https://vercel.com/new). Vercel detects static HTML/CSS/JS and deploys with the included `vercel.json` within seconds!
